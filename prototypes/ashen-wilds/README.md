# 烽火三国：乱世求生（可玩原型）

## 启动

仓库根目录运行 `python3 -m http.server 8000`，打开：

- **细化试玩版（奖励、战斗节奏、装备与 Boss 反馈）**：<http://localhost:8000/prototypes/ashen-wilds/play-polished.html>
- 原始构建：<http://localhost:8000/prototypes/ashen-wilds/index.html>

细化试玩版从同目录读取 `index.html`，检查每个补丁锚点恰好匹配一次后再启动；代码不匹配会显示明确错误，不会静默运行部分补丁。必须经 HTTP 打开。

## 细化内容

- **战斗节奏**：开局三只小怪；前 15 秒每秒 1.5 只，15–60 秒恢复每秒 3 只，60 秒后每秒 1 只，保留精英/Boss 定时登场。
- **奖励面板**：卡组在展示时固定快照；选中后锁定面板并禁用所有卡片，阻止连点重复结算；处理器强制验证技能卡/装备卡类型。
- **装备流程**：优先填未装备槽位（同一抽卡最多一件/槽），槽位填满后才抽同件升级，最后才抽替换；穿戴、升级与替换走同一个装备应用函数。替换确认应用新装备，取消返回原卡组；只有开箱奖励队列完成才清箱并递增价格。
- **精英/Boss反馈**：精英血条显示警戒/追击状态；Boss 锁定落点攻击有更长预警，并通过提示条和头顶标签区分落点锁定与扇形攻击。精英/Boss击杀奖励仍依次为 1+1、2+2；最终 Boss 奖励完成后再结算胜利。
- **目标优先级**：单体技能在技能射程内优先选择仇恨范围内最近的精英/Boss，否则攻击最近敌人；范围技能保持原判定。

## 回归测试

1. 打开 `play-polished.html`，确认无“补丁锚点不匹配”；进入游戏。
2. 前 15 秒观察小怪刷新较稀疏，15 秒后密度提高，60 秒后降低；开局场上应只有初始三只，后续才刷怪。
3. 升级只出现技能卡且只改变技能栏；宝箱只出现装备卡且只改变装备槽。
4. 反复快速点击奖励卡只结算一次。宝箱取消替换保留原装备与原卡组选项，确认后装备替换；只有宝箱流程完成才递增箱价。
5. 空槽装备卡优先于升级和替换；槽位全满后可升级，之后才允许替换。
6. 精英击杀得到技能×1和装备×1；Boss击杀得到技能×2和装备×2。击杀最后一只 Boss 后完成奖励再胜利结算。
7. Boss攻击开始时检查落点锁定/扇形提示、预警圈和头顶状态标签；精英血条状态应在警戒和追击间变化。
8. 单体技能检查仇恨范围内精英/Boss优先；范围技能仍按原范围命中。
