# 烽火三国：乱世求生（可玩原型）

## 启动

仓库根目录运行 `python3 -m http.server 8000`，打开：

- 奖励隔离 + 精英/Boss优先攻击：<http://localhost:8000/prototypes/ashen-wilds/play-priority.html>
- 原始构建：<http://localhost:8000/prototypes/ashen-wilds/index.html>

必须经 HTTP 打开，不能直接使用 `file://`。修正版从同目录读取 `index.html`，检查补丁锚点全部唯一匹配后再应用修改；代码版本不符会报错停止。

## 奖励、装备及节奏细化

- 技能池和装备池、抽卡函数及选择处理器严格分离。升级只产生技能卡并只改技能栏；宝箱只产生装备卡并只改装备槽。应用时再次检查卡片类型。
- 开箱才扣金币；仅开箱奖励队列结束时销毁/刷新宝箱并递增价格。精英/Boss奖励不会误消耗场上宝箱或改变价格。
- 宝箱装备抽卡优先给尚未填充的独立槽位（同一抽卡最多一张/槽），槽位补齐后再提供装备升级，最后才出现替换卡。替换和强化均通过统一装备处理函数；替换需确认，取消回到同一组选项且不会换卡。
- 奖励面板选择期间禁用重复点击，保留当前卡组快照。精英击杀依次发技能×1、装备×1；Boss击杀依次发技能×2、装备×2。第五只Boss的胜利结算等全部奖励完成后触发。
- 单体技能在技能射程内优先攻击仇恨范围（235世界单位）内最近精英/Boss；没有合格目标时攻击范围内最近敌人。圆形/扇形技能不变。
- 世界800×1200，开局3只小怪；1秒宽限后0–60秒每秒3只、之后每秒1只。基础防御40，小怪/精英/Boss普通接触伤害分别为1/2/4，之后应用装备减伤。Boss技能继续使用预警机制。
- 精英/Boss显示血条；精英进仇恨范围后才追击，Boss已有远程落点与扇形攻击的预警、躲避反馈。

## 回归测试

1. 升级只显示技能卡，选择后只改变技能栏；无技能卡可进入装备槽。
2. 宝箱只显示装备卡，选择后只改变装备槽；无装备卡可进入技能栏。检查金币、箱子刷新和价格递增只在开箱完成时发生。
3. 新开局时装备槽未满，抽卡优先填空槽且不同时出现多个同槽新装备；槽位全满后可升级，替换卡需确认，取消返回原卡组。
4. 奖励卡连续快速点击，只能结算一次。精英奖励为技能1次+装备1次；Boss为技能2次+装备2次；地面箱不会被击杀奖励误清除。
5. 击败第5只Boss后先完成四项奖励再胜利结算。
6. 单体技能优先攻击仇恨范围内最近精英/Boss；不在仇恨范围时回退最近敌人；范围技能保持不变。
7. 开局检查仅3只小怪，约1秒后正常刷怪开始；基础防御40时普通接触伤害为1、2、4。
