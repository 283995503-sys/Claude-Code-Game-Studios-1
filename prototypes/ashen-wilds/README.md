# 灰烬荒野（Ashen Wilds）— 可玩原型

一个受生存类 Roguelike 核心循环启发、使用原创名称与程序化图形制作的浏览器原型。它不包含《Azeroth Survivors》或《魔兽世界》的代码、素材或专有游戏数据。

## 试玩

无需安装依赖或构建工具：用现代浏览器直接打开 `index.html` 即可。若浏览器限制本地文件，可在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/prototypes/ashen-wilds/>。

## 操作

- **WASD / 方向键**：移动
- **空格 / Shift**：冲刺（有冷却时间，冲刺时短暂无敌）
- **自动攻击**：法术自动瞄准最近的敌人
- **升级**：收集敌人掉落的灵光升级；每次升级选择一项强化
- **Esc**：暂停 / 继续
- **触屏**：左下虚拟摇杆移动，右下按钮冲刺

生存 3 分钟即可完成试炼；倒下后可以立即重新开始。荒野巨兽会在第 1、2 分钟出现。

## 原型范围与验证

本原型使用原生 Canvas 和内嵌 JavaScript/CSS，无外部库、网络请求或下载素材。代码把主要调优参数集中在 `CONFIG` 中，方便后续依据试玩反馈调整。
