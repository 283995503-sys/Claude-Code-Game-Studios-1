## 奖励规则

技能池/装备池、抽卡函数和选择处理函数独立。升级只发技能卡并只改技能栏；宝箱只发装备卡并只改装备槽。技能卡和装备卡会按类型校验，拒绝跨类型应用。金币扣除、宝箱价格递增与替换确认仅属开箱流程；精英/Boss奖励不会消费地面宝箱或改变宝箱价格。精英击杀奖励依次为技能×1、装备×1；Boss击杀奖励依次为技能×2、装备×2。第五只Boss的胜利结算等四次奖励选完后才触发。

## 战斗规则

单体 `single` / `lottery` 技能在自身射程内优先选择仇恨半径内（235世界单位）最近的精英或Boss；没有合格目标时攻击射程内最近敌人。圆形/扇形范围技能行为不变。开局生成3只小怪，1秒后开始正常刷怪。基础防御40时，小怪/精英/Boss普攻伤害分别为1/2/4，之后应用装备减伤。地图800×1200，其他刷怪与宝箱规则见游戏内实现。

## 回归测试

1. 升级只出现技能卡，选择后只改变技能栏；宝箱只出现装备卡，选择后只改变装备槽。
2. 宝箱替换取消保留原装备；确认才替换，宝箱价格只在宝箱奖励全部完成后递增。
3. 精英击杀完成一次技能+一次装备选择；Boss击杀完成两次技能+两次装备选择，期间不误消耗场上宝箱。
4. 击杀第五只Boss后先完成奖励队列，再出现胜利结算。
5. 单体技能优先攻击仇恨半径内最近精英/Boss；没有优先目标时回退最近敌人。范围技能命中逻辑不变。
6. 开局检查恰好三只小怪；约1秒后正常刷怪开始。
