# 烽火三国：乱世求生（可玩原型）

单文件浏览器生存游戏，使用 Canvas 程序绘图表现原创三国题材的 Q 版武将、敌兵、宝箱与战场。无外部依赖、素材下载或服务端。**当前是细节丰富的程序化占位美术，不是外部高清贴图；如需真正贴图级精细美术，需要后续创作/授权图像素材并接入。**不包含《魔兽世界》或《Azeroth Survivors》的专有素材。

## 本地试玩

下载 [`index.html`](./index.html) 后使用 Chrome、Edge、Firefox 等现代浏览器打开。若希望使用本地服务器，在仓库根目录执行：

```bash
python3 -m http.server 8000
```

然后浏览 `http://localhost:8000/prototypes/ashen-wilds/`。

## 操作

- WASD / 方向键：移动
- 空格 / Shift：闪避（短暂无敌，冷却 3 秒）
- 自动攻击：技能自动寻找目标；无需点击攻击
- Esc：暂停
- 触屏：左侧虚拟摇杆移动，右侧按钮闪避

## 当前实现

- 角色自动攻击；每个技能按自身范围/圆形半径或扇形判定，不以固定命中人数截断。
- 单体雷击每次随机抽取 1–3 段，并为每段独立随机伤害倍率。
- 技能栏最多 6 个技能；升级三选一。技能已有时，同名技能卡升级该技能；已满 6 个后不再出现新技能卡。
- 开局生成一个场景宝箱；靠近自动开启并暂停战斗，三选一后宝箱消失。每击杀 15 只小怪刷新下一箱。场上有未拾取宝箱时击杀计数暂停，打开后计数归零。
- 五个装备栏：武器、盾牌、护甲、坐骑、饰品。空栏优先给尚未拥有的对应装备；同栏唯一。重复同名装备只升级该件装备。槽位已有另一件装备时，先展示新旧属性并弹出确认；确认替换，取消保留。
- 小怪护甲初始较低，并随角色伤害缓慢增长。精英按当前攻击力的 20 倍设防御值，再使用递减曲线换算伤害，避免平面减法导致完全打不动。
- Boss 远程技能预警 1 秒，之后攻击预警点，未离开范围即秒杀；弧形技能同样预警 1 秒，玩家可移动闪出扇形区域。

## 刷怪时间假设

1. 游戏时间从点击“开始征战”起算。
2. 0–60 秒每秒 3 只小怪；60 秒后每秒 1 只，维持战场压力直至结算。小怪上限 100，超过上限时略过本次生成。
3. 精英 5 轮开始时点为 60、300、540、780、1020 秒。每轮 4 只，分别在开始时点、+20、+40、+60 秒生成；所以第 1 轮恰好在 60/80/100/120 秒生成。
4. Boss 在 240、480、720、960、1200 秒各生成 1 只；第 5 只 Boss 被击杀后立即结算胜利。若玩家先阵亡则失败结算。Boss 生成时间不因其他菜单/升级界面而改变，因为选择界面暂停模拟时间。
5. 精英不主动追击；玩家进入 235 像素仇恨范围后，该精英永久进入追击状态。精英防御按“当前玩家攻击力 ×20”作为防御值，采用 `攻击²/(攻击+防御)` 的曲线减伤（最少 1 点），以使高防御仍可被击败。
6. 宝箱计数只统计小怪击杀；精英和 Boss 不推进 15 击杀计数。场上有宝箱时计数暂停；宝箱开完后归零。宝箱选择装备替换时，取消将关闭确认框并回到奖励选择，宝箱仍在场。
7. 装备属性按等级线性叠加，栏位中同一时刻只有一件。技能与装备的升级仅由对应同名技能/装备卡触发；装备替换不会把不同装备合并升级。
