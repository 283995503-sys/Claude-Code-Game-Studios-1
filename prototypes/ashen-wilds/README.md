# 烽火三国：乱世求生（可玩原型）

单文件 Canvas 浏览器生存游戏，使用原创三国题材程序化 Q 版美术，无外部依赖。美术仍为程序化原型，不是精细外部贴图。

## 启动

推荐用本地服务器运行（避免浏览器对 `file://` 的跨文件读取限制）：

```bash
python3 -m http.server 8000
```

然后打开：

- **精英/Boss优先选目标修正版**：<http://localhost:8000/prototypes/ashen-wilds/play-priority.html>
- 原始构建：<http://localhost:8000/prototypes/ashen-wilds/index.html>

修正版启动页会读取 `index.html` 并在载入时对单体技能的目标选择应用一个受校验的补丁；若原型代码结构不匹配会明确报错，不会静默运行错误版本。

## 操作

- WASD / 方向键：移动
- 空格 / Shift：闪避
- Esc：暂停
- 自动施放技能；触屏可用左侧摇杆与右侧闪避按钮

## 单体技能目标优先级

仅对 `single` 和 `lottery` 单体技能生效：在技能自身射程内，若有精英或 Boss 同时位于玩家仇恨半径（235 世界单位）内，优先攻击距离最近的精英/Boss；没有合格精英/Boss 时，再攻击射程内最近目标。圆形和扇形范围技能原有的范围命中规则不变。精英离开仇恨范围后也不享受优先级。

## 已有玩法规则摘要

- 地图尺寸 800×1200，镜头跟随玩家。
- 开局立即刷新 3 只小怪；1 秒引导宽限后进入常规刷怪节奏（0–60 秒每秒 3 只，之后每秒 1 只）。
- 基础角色防御为 40。普通接触攻击伤害 = 防御 / 系数：小怪 1/40（基础伤害 1）、精英 1/20（2）、Boss 普攻 1/10（4）；装备减伤在比例计算后应用。Boss 特殊技能按其预警规则处理。
- 角色升级只从独立技能池抽取三选一，并只修改技能栏；宝箱只从独立装备池抽取三选一，并只修改装备槽。技能卡和装备卡绝不混池。
- 精英击杀奖励队列：技能三选一 1 次，然后装备三选一 1 次。Boss 击杀奖励队列：技能三选一 2 次，然后装备三选一 2 次。战斗在奖励队列完成前暂停。
- 宝箱付费、金币扣除、价格递增和装备替换确认只属于装备奖励流程。

## 测试清单

1. 启动 `play-priority.html`，检查页面能加载并正常进入战斗；查看控制台无语法或加载错误。
2. 在 235 单位仇恨半径内同时让小怪和精英/Boss 进入同一单体技能射程，检查单体技能先命中最近的精英/Boss。
3. 当精英/Boss 都离开仇恨范围后，检查单体技能回退为攻击射程内最近目标。
4. 检查圆形、扇形技能仍按原范围命中；不因单体优先规则改变。
5. 复测奖励隔离、精英 1+1 奖励队列、Boss 2+2 奖励队列，以及开局仅三只小怪。

当前环境不能启动真实浏览器，以上属于待本机执行的回归步骤；不能据此宣称已完成实际浏览器运行测试。
