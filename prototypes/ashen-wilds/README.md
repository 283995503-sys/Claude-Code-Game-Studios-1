# 烽火三国：乱世求生（可玩原型）

单文件浏览器生存游戏，使用 Canvas 程序绘图表现原创三国题材 Q 版武将、敌兵、宝箱与战场。无外部依赖。美术为程序化原型，不是外部高清贴图；不含《魔兽世界》或《Azeroth Survivors》专有素材。

## 本地试玩

使用现代浏览器打开 `index.html`。或者在仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/prototypes/ashen-wilds/`。

## 操作

- WASD / 方向键：移动；空格 / Shift：闪避；Esc：暂停。
- 自动攻击，技能自动选择目标。
- 手机：左侧虚拟摇杆，右侧闪避按钮。

## 独立奖励系统

奖励逻辑、数据存储与配置按奖励类型严格隔离，不使用混合奖励数组：

- **角色升级奖励类型 `skill`**：经验升级只调用 `buildLevelSkillCards()`，只读取 `SKILL_POOL`，只由 `applySkillUpgrade()` 写入 `game.skills`。三选一提供新技能或已有技能等级；技能槽上限为 6，满槽后不生成新技能卡。技能配置独立于宝箱价格、装备栏和金币。
- **宝箱奖励类型 `equipment`**：付费开启宝箱只调用 `buildChestEquipmentCards()`，只读取 `EQUIPMENT_POOL`，只由 `applyEquipmentReward()` 写入 `game.gear`。可提供新装备、同名装备强化或不同装备替换；替换必须经过独立确认弹窗。宝箱奖励不访问技能池，也不会改变技能栏。
- **显式类型校验**：每次展示分别设置 `activeRewardType`；技能选择只接受 `skill-new` / `skill-upgrade`，装备选择只接受 `equipment-*`。无法跨类型套用奖励卡。`REWARD_CONFIG` 分别声明两个卡池的规则。
- **宝箱购买**：开局生成价格 25 的箱子并赠送 25 金币。每五个小怪击杀获得 3 金币；精英 +25；Boss +150。宝箱价格按初始 `a₁=25, g₁=13` 递推，购买后先加当前差价，再计算下一个差价 `round(1.3×g)`，因此售价为 25、38、55、77……

## 世界与刷怪

- 世界坐标固定为 800×1200，镜头跟随玩家并按屏幕比例缩放。
- 小怪 0–60 秒每秒 3 只，之后每秒 1 只；每累计击杀 15 只小怪生成一个地面宝箱（若已有宝箱则不重复）。
- 精英五轮开始时间为 60、300、540、780、1020 秒，每轮 4 只、每 20 秒一只；以玩家为中心按北、东、南、西依次生成。精英刷新显示提示，不主动追击；玩家进入 235 世界单位仇恨范围才开始追击。
- Boss 在 240、480、720、960、1200 秒生成；第 5 只被击杀后胜利结算。远程攻击预警 1 秒，未离开标记落点即秒杀；扇形攻击预警后可走位躲避。
- 精英和 Boss 均显示头顶血条。
