# 烽火三国：乱世求生（可玩原型）

单文件 Canvas 浏览器生存游戏，使用原创三国题材程序化 Q 版美术。当前原型无外部依赖；美术仍为程序化占位，不是精细外部贴图。

## 本地试玩

在仓库根目录运行 `python3 -m http.server 8000`，然后打开：

- 奖励隔离 + 精英/Boss优先攻击修正版：<http://localhost:8000/prototypes/ashen-wilds/play-priority.html>
- 原始构建：<http://localhost:8000/prototypes/ashen-wilds/index.html>

修正版需与 `index.html` 放在同一目录，通过 HTTP 访问。启动页会先核验若干代码锚点并应用小范围补丁；若源文件版本不匹配，会报错停止，不会静默运行错误构建。

## 奖励流程（修正版）

奖励类型使用独立配置池、抽卡函数、选择处理函数和存储路径：

- **角色升级**：只从技能池生成三选一；卡片仅含技能新增或同技能升级，处理器只写 `game.skills`。
- **开启宝箱**：先检查并扣金币，再只从装备池抽三选一；卡片仅含装备穿戴/同件强化/替换，处理器只写 `game.gear`。宝箱价格递增、宝箱销毁/刷新、装备替换确认只属于宝箱奖励来源。
- **精英击杀**：排队一次技能三选一，再一次装备三选一。
- **Boss 击杀**：排队两次技能三选一，再两次装备三选一。
- 每张奖励卡在选择时再次验证类型：技能流程拒绝非 `skill-*` 卡，装备流程拒绝非 `equipment-*` 卡。精英/Boss 奖励结束不会误消耗地面宝箱，也不会递增宝箱价格。

## 单体技能目标规则

对单体 `single` / `lottery` 技能，在技能射程内优先选择仇恨半径（235 世界单位）内最近的精英或 Boss；没有符合条件的精英/Boss 时，回退到射程内最近目标。圆形/扇形范围技能保持原判定逻辑。

## 其他规则

- 世界坐标 800×1200，镜头跟随玩家。
- 开局立即刷新 3 只小怪；1 秒宽限后进入常规刷怪节奏（0–60 秒每秒 3 只，之后每秒 1 只）。
- 基础角色防御 40；普通接触伤害=当前防御/类型系数：小怪 1/40、精英 1/20、Boss 普攻 1/10（基础防御下分别 1、2、4 点），然后应用装备减伤。Boss 特殊技能仍遵循预警规则。
- 宝箱价格为 25、38、55、77……；金币：每 5 只小怪 +3、精英 +25、Boss +150。精英刷新按 60/300/540/780/1020 秒轮次，每轮 4 只、间隔 20 秒；Boss 于 240/480/720/960/1200 秒生成。

## 回归测试

1. 启动修正版后，经验升级只出现技能卡；选择后只改变技能栏。
2. 金币足够时开宝箱，只出现装备卡；选择装备不会增加技能。检查金币扣除、箱子刷新、价格递增。
3. 宝箱替换装备时，取消保留原装备；确认才替换。
4. 击杀精英后按顺序出现 1 技能 + 1 装备选择；击杀 Boss 后出现 2 技能 + 2 装备选择。期间地面宝箱不应被误消耗，宝箱价格也不应变化。
5. 验证技能卡不会被装备奖励处理器接受，装备卡不会被技能奖励处理器接受。
6. 235 单位仇恨范围内有精英/Boss时，单体技能在射程内优先选最近的精英/Boss；没有优先目标时回退到最近敌人；范围技能保持原效果。
7. 开局检查只有 3 只小怪；约 1 秒后正常波次开始。
